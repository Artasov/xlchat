## Что это

`xlchat` - NeoForge-мод для Minecraft 1.21.1, сейчас используется как клиентский фильтр чата.
Мод загружается на `BOTH`, но рабочая логика завязана на client chat event.

## Что меняет

- Создает локальный файл фильтров чата и читает из него список строк.
- Скрывает входящие сообщения чата, если сообщение содержит одну из строк фильтра.
- Добавляет команду `/xlchat` для управления/перезагрузки фильтра.

## Важные файлы

- `src/main/java/com/xlchat/Core.java` - точка входа мода.
- `src/main/java/com/xlchat/ChatFilterMod.java` - файл фильтров, обработчик чата и команда.
- `src/main/templates/META-INF/neoforge.mods.toml` - metadata мода.

## Проверка
